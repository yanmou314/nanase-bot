# bnet_verify 入群验证（战网 ID）

主人按群开启后，机器人自动核验加群申请：申请人在验证问题里填写的战网 ID 会被送去
overstats 查询守望先锋档案——查到成绩自动通过，查不到则拒绝并告知"战网ID不正确"。

## 前置条件

1. **机器人必须是该群管理员**（开启命令时会自动检查并提醒）。
2. **群验证问题需要手动设置一次**（群设置 → 加群方式 → 需要验证信息，问题写
   "请填写你的战网ID（格式：名字#12345）"）。OneBot 协议不支持机器人代设验证问题。
3. overstats 服务（127.0.0.1:18080）在线；可用环境变量 `OW_API_BASE` 覆盖地址。
4. 大神档案仅覆盖**国服**数据，外服玩家查不到成绩会被拒绝。

## 主人命令

| 命令 | 说明 |
|------|------|
| `.战网验证开启 [群号]` | 开启；在目标群发送可省略群号，私聊/其他群需带群号 |
| `.战网验证关闭 [群号]` | 关闭；关闭后该群申请转回 request_manager 人工流程 |
| `.战网验证`（或 `.战网验证状态`） | 查看已开启的群列表与用法 |

## 处理逻辑

- **申请附言整体即为战网ID**（不做提取，仅裁剪空白、全角`＃`归一）；附言为空：**拒绝**，理由"战网ID不能为空"。
- 调用 `/api/v2/dashen-profile` 查询：`ok` → **通过**（并私聊通知主人）；`bnet_not_found` → **拒绝**，
  理由"战网ID不正确：未查询到 xxx 的守望先锋成绩，请核对名字大小写和 # 后面的数字后重新申请"。
- **通过后自动**：
  - 把新成员的**群名片改为战网ID**（审批通过到成员实际进群有几秒延迟，异步重试最多 5 次）；
  - 把 QQ 与战网ID**自动绑定**进 owstats 绑定表——成员进群即可直接使用 `.战报`/`.段位`/`.总结` 等命令，无需再 `.绑定`。
- 查询超时/上游异常：**不通过也不拒绝**，申请保持待处理，私聊通知主人人工处理。
- 开启该插件的群由本插件全权处理，request_manager 会自动跳过，不会双重转发。

## 与 request_manager 的关系

`request_manager` 对 `bnet_verify.is_managed_group()` 为真的群直接跳过（含关键字自动通过），
两套流程不会对同一个申请重复响应。两者都关闭/未开启的群行为不变。
